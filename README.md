## طريقة الرفع والاستضافة على GitHub Pages (مجاناً 100%)

المشروع مبني بالكامل كـ Static Web Application (HTML5 / Vanilla CSS3 / Modern JS) وبدون أي متطلبات سيرفر، وهو مهيأ تماماً ليعمل فوراً وبأعلى سرعة على **GitHub Pages**.

### الخطوات في دقيقتين:

1. **إنشاء مستودع جديد على GitHub:**
   - ادخل على حسابك في GitHub وأنشئ مستودعاً جديداً باسم (مثلاً `engagement` أو `wedding-invite`).
   - اجعل المستودع **Public**.

2. **رفع الملفات من جهازك:**
   افتح موجه الأوامر (Terminal) في مجلد المشروع ونفّذ الأوامر التالية:
   ```bash
   git init
   git add .
   git commit -m "Initial release: Ammar & Sarah engagement invitation"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```

3. **تفعيل GitHub Pages:**
   - من صفحة المستودع على GitHub ادخل على **Settings** > **Pages**.
   - تحت قسم **Build and deployment**:
     - اختر Source: `Deploy from a branch`
     - اختر Branch: `main` والمجلد `/ (root)`
     - اضغط **Save**.
   - خلال ثوانٍ سيظهر لك رابط الموقع الرسمي:
     `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`
